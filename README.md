# 📒 나만의 오답노트

초등 고학년부터 고등학생까지 쓰는 **온라인 오답노트**입니다. 국어, 수학, 영어, 사회, 과학 다섯 과목을 지원합니다.
GitHub Pages에서 바로 열리는 웹사이트이고, 기록은 Firebase에 저장됩니다. **비용은 0원**입니다.

## 주요 기능

1. **📷 틀린 문제 찍기**: 카메라로 찍거나 앨범에서 고르면 과목별 오답노트에 기록됩니다.
2. **🤔 틀린 이유 체크**: 과목마다 다른 틀린 이유 체크리스트가 나옵니다. 기타 이유는 직접 쓸 수 있습니다.
3. **💡 핵심 개념**: AI가 사진 속 문제를 읽고 개념·원리, 꼭 알아야 할 점, 실수 방지 TIP을 정리합니다.
   팁은 아이가 고른 틀린 이유에 맞춰 나옵니다.
4. **✏️ 같은 유형 문제 3개**: 3개를 모두 맞히면 **학습 완료**로 옮겨집니다.
   하나라도 틀리면 격려 메시지와 함께 틀린 문제의 해설을 보여 주고, **새 문제 3개**를 추가로 냅니다.
   모두 맞힐 때까지 반복합니다.
5. **👨‍👩‍👧 계정별 분리**: 아이디와 비밀번호로 로그인합니다. 아이마다 자기 오답노트만 볼 수 있습니다.

### 문제는 어떻게 만들어지나요? (AI + 문제은행)

| 상황 | 동작 |
|---|---|
| 평소 | **Firebase AI Logic(구글 Gemini, 무료 사용량)** 이 사진을 분석해 개념 정리와 유사문제를 만듭니다. |
| AI를 쓸 수 없을 때 (하루 무료 사용량 초과, 인터넷 문제, 흐린 사진 등) | **내장 문제은행**에서 비슷한 단원을 골라 연습합니다. 수학은 숫자를 바꿔 문제를 무한히 만들어 냅니다. |

내장 문제은행에는 과목별로 초등·중학·고등 단원 23개가 들어 있습니다.
부모님이 **설정 → 문제은행 관리**에서 단원을 직접 추가할 수도 있습니다(가족 공용).

## 🛠 처음 한 번만 하는 설정 (약 15분)

> 준비물: 구글 계정 1개 (부모님 계정 권장). 카드 등록은 필요 없습니다.

### 1단계. Firebase 프로젝트 만들기
1. <https://console.firebase.google.com> 에 구글 계정으로 접속합니다.
2. **[프로젝트 만들기]** 를 누르고 이름을 정합니다(예: `ohdap-note`). 계속을 누릅니다.
3. "Google 애널리틱스"는 **사용 안 함**으로 두어도 됩니다. **[프로젝트 만들기]** 를 누르고 완료될 때까지 기다립니다.

### 2단계. 웹 앱 등록 → 설정값을 사이트에 넣기
1. 프로젝트 첫 화면 가운데의 **웹 아이콘 `</>`** 를 누릅니다.
2. 앱 닉네임(예: `오답노트`)을 입력하고 **[앱 등록]** 을 누릅니다. "Firebase 호스팅"은 체크하지 않습니다.
3. 화면에 나온 코드 중 `const firebaseConfig = { ... };` 부분의 **중괄호 안 값**(apiKey, authDomain … appId)을 복사해 둡니다.
4. GitHub 저장소에서 `js/firebase-config.js` 파일을 열고 오른쪽 위 **연필(✏️) 아이콘**을 누릅니다.
5. `YOUR_API_KEY` 등이 들어 있는 6줄을 복사한 값으로 바꿉니다. 그다음 **[Commit changes…] → [Commit changes]** 를 누릅니다.

```js
export const firebaseConfig = {
  apiKey: "AIza....",
  authDomain: "ohdap-note.firebaseapp.com",
  projectId: "ohdap-note",
  storageBucket: "ohdap-note.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef",
};
```

> 💡 이 값은 사이트 주소처럼 공개돼도 괜찮은 값입니다. 데이터는 4단계의 보안 규칙이 지켜 줍니다.

### 3단계. 로그인(아이디·비밀번호) 켜기
1. 왼쪽 메뉴에서 **빌드 → Authentication** 으로 가서 **[시작하기]** 를 누릅니다.
2. **Sign-in method** 탭에서 **이메일/비밀번호**를 고릅니다. 첫 번째 스위치를 **사용 설정**으로 바꾸고 **[저장]** 을 누릅니다.
   (화면에서는 "아이디"로 가입하지만, 내부적으로 이메일 로그인 기능을 사용합니다. 실제 메일은 보내지 않습니다.)
3. **Settings** 탭 → **승인된 도메인** → **[도메인 추가]** 에 아래 주소를 넣고 추가합니다.
   ```
   na7611na.github.io
   ```

### 4단계. 데이터베이스(Firestore) 만들기
1. 왼쪽 메뉴에서 **빌드 → Firestore Database** 로 가서 **[데이터베이스 만들기]** 를 누릅니다.
2. 버전은 **Standard**, 위치는 **asia-northeast3 (서울)** 을 고르고 다음을 누릅니다.
3. **프로덕션 모드에서 시작**을 고르고 **[만들기]** 를 누릅니다.
4. 만들어지면 **규칙** 탭으로 갑니다. 내용을 모두 지우고 이 저장소의 [`firestore.rules`](firestore.rules) 내용을 붙여넣은 뒤 **[게시]** 를 누릅니다.

### 5단계. 무료 AI 켜기 (Firebase AI Logic)
1. 왼쪽 메뉴에서 **AI → AI Logic** 으로 가서 **[시작하기]** 를 누릅니다.
2. **Gemini Developer API** 를 고릅니다. **Spark(무료) 요금제 그대로** 사용할 수 있습니다.
   "Vertex AI / Agent Platform"은 유료 요금제가 필요하니 고르지 않습니다.
3. 안내에 따라 **[API 사용 설정]** 을 누르면 끝입니다. 코드는 이미 들어 있어서 따로 붙여넣을 필요가 없습니다.

### 6단계. GitHub Pages로 사이트 열기
1. GitHub 저장소에서 **Settings → Pages** 로 갑니다.
2. **Source: Deploy from a branch**, **Branch: `main` / `(root)`** 를 고르고 **[Save]** 를 누릅니다.
3. 1~2분 뒤 아래 주소로 접속합니다.
   **<https://na7611na.github.io/Review-notes-for-wrong-answers/>**
4. 휴대폰이나 태블릿에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.
   (아이폰: 사파리 공유 버튼 → 홈 화면에 추가 / 안드로이드: 크롬 메뉴 → 홈 화면에 추가)

### 7단계. 아이별 계정 만들기
1. 사이트에서 **회원가입** 탭을 누릅니다. 아이디, 비밀번호, 이름, 학년을 입력해 아이마다 따로 가입합니다.
2. **(권장) 두 아이 모두 가입했으면 새 가입을 막아 두세요.** 모르는 사람이 사이트 주소를 알아도 가입할 수 없게 됩니다.
   Firebase 콘솔 → Authentication → **Settings → 사용자 작업(User actions)** 에서 **"생성(가입) 사용 설정"** 체크를 끄고 저장합니다.
   나중에 계정을 더 만들려면 잠깐 다시 켜면 됩니다.

## 💰 비용 (무료 범위)

| 항목 | 무료 한도 | 우리 집 사용량 |
|---|---|---|
| Firestore 저장 공간 | 1GiB | 사진 1장 약 0.3~0.6MB → **약 2,000장 이상** |
| Firestore 읽기/쓰기 | 하루 5만/2만 회 | 하루 수백 회 수준 |
| Gemini(AI Logic) | 모델별 하루·분당 무료 요청 한도 | 두 아이가 하루 수십 문제 기록 시 충분 |

무료 요청 한도를 넘으면 그날은 자동으로 **문제은행**으로 대체됩니다. 요금이 청구되지는 않습니다(Spark 요금제는 결제 수단이 없음).

## ❓ 문제가 생겼을 때

| 증상 | 해결 |
|---|---|
| "오답노트 설정이 필요해요" 화면이 나와요 | 2단계 `js/firebase-config.js` 수정을 확인하세요. |
| 로그인 시 "승인된 도메인" 오류 | 3단계-3 `na7611na.github.io` 추가를 확인하세요. |
| "이메일/비밀번호 로그인을 켜 주세요" | 3단계-2를 확인하세요. |
| 저장·불러오기 실패 | 4단계 Firestore 생성과 규칙 게시를 확인하세요. |
| 항상 "AI가 분석하지 못했어요"가 나와요 | 5단계(AI Logic, Gemini Developer API)를 확인하세요. 모델이 종료됐다면 `js/firebase-config.js`의 `AI_MODELS` 맨 앞에 새 모델 이름을 추가하세요. |
| 수정한 내용이 사이트에 안 보여요 | 1~2분 기다린 뒤 새로고침(캐시 때문에 안 되면 브라우저 탭을 닫았다 열기)하세요. |

## ✍️ 문제은행에 단원 추가하는 형식

설정 → 문제은행 관리 → 새 단원 추가에서 문제를 아래 형식으로 붙여넣습니다. 문제와 문제 사이는 **빈 줄**로 구분하고, 최소 3문제가 필요합니다.

```
Q: 3 + 4 × 2 의 값은?
1) 14
2) 11
3) 10
4) 9
정답: 2
해설: 곱셈을 먼저 계산해요. 4 × 2 = 8, 3 + 8 = 11

Q: 다음 문제…
1) …
2) …
3) …
4) …
정답: 1
해설: …
```

## 📁 파일 구조

```
index.html            화면 뼈대
css/style.css         디자인
js/firebase-config.js Firebase 설정값 + 사용할 AI 모델 (여기만 수정하면 됨)
js/app.js             화면과 동작 (기록, 상세, 문제 풀기, 설정)
js/db.js              로그인·데이터 저장 (Firebase Auth, Firestore)
js/ai.js              AI 분석·유사문제 생성 (Firebase AI Logic)
js/bank.js            내장 문제은행 + 수학 자동 출제
js/data.js            과목, 학년, 과목별 틀린 이유, 격려·칭찬 메시지
firestore.rules       데이터 보안 규칙 (4단계에서 붙여넣기)
```

과목별 틀린 이유나 격려 메시지를 바꾸려면 `js/data.js` 를 수정하면 됩니다.
